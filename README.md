# 🌸 «Цветочный Рай» — Интернет-магазин цветов и подарков (г. Горловка)

Современный, быстрый и полностью адаптивный интернет-магазин цветов, авторских букетов и подарков с интерактивной картой зон доставки по Горловке, живым поиском, корзиной, избранным и пошаговым оформлением заказа.

---

## 🌟 Основные возможности

- **Каталог товаров (260+ позиций)**:
  - Авторские букеты, цветы в шляпных коробках и корзинах, WOW-букеты, гелиевые шары, мягкие игрушки, комнатные растения и свадебная флористика.
  - Динамическая фильтрация по подкатегориям через свайп-ленту с 3D-иконками.
  - Сортировка по популярности, цене (по возрастанию / убыванию) и рейтингу.
- **Интерактивная карта доставки по Горловке**:
  - 25 официальных зон доставки с полигональными границами (ЦГР, Строитель, Майский, Кочегарка, Короленко, Комсомолец, Новогорловка и др.).
  - Автоматический расчет стоимости и времени доставки при выборе точки на карте или вводе адреса.
- **Полноэкранный живой поиск**:
  - Быстрый поиск по названию, категории и тегам с выпадающими подсказками и карточками предпросмотра.
  - Автозакрытие оверлея при переходе к товару или в каталог.
- **Быстрый просмотр букета (Quick View Modal)**:
  - Фотографии высокого качества, выбор размера (Обычный, Большой, Огромный), бейджи преимуществ, условия получения и состав букета.
  - Промокод на первый заказ с кнопкой быстрого копирования.
- **Корзина и список избранного**:
  - Удобные боковые панели (Drawers) с сохранением состояния в `localStorage`.
  - Изменение количества, расчет итоговой суммы и защита от случайного сброса.
- **Оформление заказа (Checkout)**:
  - Выбор способа получения (курьерская доставка / самовывоз из магазина).
  - Ввод адреса с интерактивной подсказкой и опцией частного сектора.
  - Выбор получателя (заказ для себя / подарок другому человеку с анонимной доставкой).
  - Выбор времени (как можно скорее 40–60 мин / точная дата и временной интервал).
  - Бесплатная открытка с индивидуальным текстом и комментарии для флориста.
  - Автоматическая маска номера телефона `+7 (XXX) XXX-XX-XX`.
  - Применение промокодов (`START5`, `ГОРЛОВКА10` и др.).
  - Экран успешного заказа с номером, деталями и ссылками возврата.
- **100% Адаптивность и мобильная оптимизация**:
  - Идеальное отображение на всех экранах: мобильные (320px, 375px, 480px), планшеты (768px, 1024px), ноутбуки и ультраширокие мониторы (1440px, 1920px).
  - Нижняя мобильная панель навигации (App Bottom Bar) для управления одной рукой.
  - Аппаратное ускорение анимаций (GPU 60fps) без рывков.

## 🛠 Стек технологий

- **Разметка и стили**: HTML5, семантические теги, CSS3 переменные (Design Tokens), Flexbox / Grid.
- **Логика**: Чистый JavaScript (Vanilla ES Modules) без тяжелых сторонних фреймворков.
- **Сборщик**: [Vite 5](https://vitejs.dev/) — сверхбыстрая компиляция и оптимизация ассетов.
- **Сервер**: Легковесный встроенный Node.js HTTP сервер со статической раздачей и SPA-маршрутизацией.
- **Тестирование**: Puppeteer Core (кросс-разрешающие визуальные и интерактивные тесты).

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу: `http://localhost:5173`

### 3. Сборка для продакшна
```bash
# Пересобрать index.html при изменении товаров:
node build_cart.mjs

# Собрать бандл в папку dist/:
npm run build
```

### 4. Запуск продакшн-сервера
```bash
npm start
```
Сервер запустится на `http://localhost:3000`

### 5. Запуск автоматических тестов
```bash
# Проверка интерактивных сценариев (поиск, корзина, чекаут, промокод):
npm test

# Полная проверка адаптивности на всех 6 брейкпоинтах (320px - 1920px):
npm run test:visual
```
